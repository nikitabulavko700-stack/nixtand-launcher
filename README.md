# nixtand-launcher

Каталог приложений для лаунчера nixtand.

- `apps.json` — список приложений, версии, ссылки на файлы, «что нового». Лаунчер читает его каждые 15 минут.
- `publish.ps1` — выпустить новую версию: `.\publish.ps1 -App nebula -Version 2.6.0 -Path "...\Nebula.exe" -Notes "Что нового"`
- `create-repo.ps1` — один раз создать этот репозиторий на GitHub.

Файлы приложений лежат в Releases этого репозитория.
